# Changelog

## 1.0.0

> This release requires Lumide 0.23.0 and later.

- Initial release, powered by `@tailwindcss/language-server`.
- Complete classes, arbitrary values, and variants, with color swatches.
- Show the generated CSS on hover.
- Lint CSS conflicts and invalid `@apply`, `@screen`, `@variant`, and `theme()` usage.
- Detect Tailwind v3 and v4 projects, including monorepo packages.
- Use the project's local server, or install it globally with npm when it is missing.
- Add a status bar item with status, restart, and server path actions.
- Support HTML, CSS, JavaScript, TypeScript, Vue, Svelte, Astro, PHP, Blade, and other templates.
